## 3. Course Description & Prerequisites
CS 402 introduces practical machine learning, Retrieval-Augmented Generation (RAG), vector representations, and stateful agentic workflows using LangChain and LangGraph. Students learn to architect, deploy, and evaluate production-ready intelligent applications.
- **Prerequisites:** CS 201 (Data Structures and Algorithms) and MATH 215 (Linear Algebra and Probability). Proficiency in Python 3.10+ is required.

## 4. Course Curriculum & Weekly Schedule
- **Week 1–2:** Fundamentals of Generative AI, Large Language Models (LLMs), and Prompt Engineering.
- **Week 3–4:** Embeddings, Distance Metrics, and Vector Databases (Chroma, FAISS).
- **Week 5–6:** Retrieval-Augmented Generation (RAG) Architecture, Document Chunking, and Context Windows.
- **Week 7:** Midterm Examination Review & Project Proposal Submission.
- **Week 8:** Midterm Examination (In-class, Thursday, October 24, 2026).
- **Week 9–10:** Agentic AI Systems, Tool Calling, and Function Schemas.
- **Week 11–12:** LangGraph Stateful Graphs, Conditional Routing, and Multi-turn Memory.
- **Week 13:** Model Evaluation, Safety, Guardrails, and Security (Prompt Injection mitigation).
- **Week 14:** Final Capstone Project Demonstrations and Peer Code Reviews.
